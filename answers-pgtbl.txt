Q:Which other xv6 system call(s) could be made faster using this shared page? Explain how.
Answer:
One system call is pipe(), which is used for inter-process communication. 
In the traditional implementation, data written to the pipe by one process is copied into the kernel buffer and then read out by another process.
With shared memory, both processes could map a shared page and use it as a circular buffer, eliminating the need to copy data.
Another example is read() when used between parent and child processes that share memory. 
Instead of copying large chunks of data via read(), processe could access the same data directly through the shared memory.
