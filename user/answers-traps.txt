1. Which registers contain arguments to functions? For example, which register holds 13 in main's call to printf?
In RISC-V, registers a0–a7 are used to pass arguments to functions. For printf in main, the value 13 is held in register a2 (the third argument).

2. Where is the call to function f in the assembly code for main? Where is the call to g? (Hint: the compiler may inline functions.)
The compiler optimized (inlined) both f and g into main. Thus:

The call to f is replaced by its inlined instructions (e.g., li a1, 12 after jal ra, printf).

The call to g is similarly inlined (e.g., addi a1, a0, 1 to compute 8+1).

3. At what address is the function printf located?
In call.asm, the printf function is called via jalr to an address loaded from the global pointer (gp). The exact address is linker-dependent but typically 0x628 (example from xv6).

4. What value is in the register ra just after the jalr to printf in main?
After jalr, ra holds the return address, which is the next instruction in main (e.g., 0x34 in call.asm).

5. Run the following code:
c
unsigned int i = 0x00646c72;
printf("H%x Wo%s", 57616, (char *) &i);
Output: He110 World

Explanation:

57616 in hex is e110 → He110.

i = 0x00646c72 is stored in little-endian as bytes 0x72 0x6c 0x64 0x00 → ASCII 'r' 'l' 'd' '\0' → World.

If RISC-V were big-endian:

To get the same output, set i = 0x726c6400 (stores bytes 0x72 0x6c 0x64 0x00 in memory).

Yes, you must change i’s value due to byte order reversal.

6. In the following code, what is printed after y=? Why?
c
printf("x=%d y=%d", 3);
Output: x=3 y=[garbage value]

Reason: Only one argument (3) is provided for two %d placeholders. The second %d reads an uninitialized value from where a2/stack would hold the second argument (undefined behavior).
